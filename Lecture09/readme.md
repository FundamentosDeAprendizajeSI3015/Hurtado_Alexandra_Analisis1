# Análisis de Clustering Financiero - UdeA

Este repositorio contiene la implementación de técnicas de aprendizaje no supervisado para analizar la estructura de datos financieros de distintas unidades académicas.
El objetivo es identificar patrones, agrupaciones y comportamientos similares entre las unidades sin utilizar etiquetas durante el entrenamiento.

# Metodología

El flujo general del análisis es:

-Carga del dataset

-Limpieza de datos

-Imputación de valores faltantes

-Escalamiento de variables

-Reducción de dimensionalidad (PCA)

-Aplicación de modelos de clustering:

-KMeans

-DBSCAN

-Evaluación de resultados

-Visualización de clusters

# Tecnologías usadas 

-Python 3

-Pandas

-NumPy

-Scikit-learn

-Matplotlib

-Seaborn

-UMAP
