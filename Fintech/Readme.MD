# Serie de Ejercicios de Clase - Analisis de Datos y Visualizacion

Este repositorio contiene una serie de ejercicios desarrollados en clase enfocados en el analisis de datos, preprocesamiento y visualizacion en contextos financieros.

Los ejercicios abordan desde la preparacion de datos para Machine Learning hasta la visualizacion de series temporales.

## Descripcion general

Los ejercicios se centran en:

- Preprocesamiento de datos reales y sinteticos  
- Analisis exploratorio de datos (EDA)  
- Ingenieria de variables  
- Preparacion de datos para modelos de Machine Learning  
- Visualizacion interactiva con Plotly  

---

## Ejercicio 1: Fintech (Dataset Sintetico)

Este ejercicio trabaja con un dataset sintetico del sector fintech.

### Objetivo

Preparar los datos para modelado mediante un flujo completo de preprocesamiento.

### Contenido

- Carga de datos (CSV + diccionario JSON)  
- Analisis exploratorio (EDA)  
- Limpieza e imputacion de datos  
- Ingenieria de variables (retornos y log-retornos)  
- Codificacion one-hot de variables categoricas  
- Escalado de variables numericas  
- Separacion temporal de train y test  
- Exportacion de datasets procesados  

### Salidas

- `fintech_train.parquet`  
- `fintech_test.parquet`  
- `processed_schema.json`  
- `features_columns.txt`  
- Grafico interactivo en HTML (Revenue por segmento)  

---

## Ejercicio 2: Analisis del Dolar USD/COP

Este ejercicio analiza el comportamiento del dolar en Colombia a partir de datos historicos.

### Objetivo

Visualizar la evolucion reciente del tipo de cambio USD/COP.

### Contenido

- Carga de datos desde CSV  
- Limpieza de datos (formato de fechas y valores monetarios)  
- Transformacion de variables  
- Filtrado de los ultimos 30 dias  
- Visualizacion interactiva con Plotly  

### Resultado

- Grafica interactiva de la TRM (USD/COP) del ultimo mes
